Most of this roster has been about agents *reading* — docs, MCP catalogs,
skill manifests. This one is the transaction stage: an AI answer engine
writing to a database on a user's behalf, not just retrieving from it. Worth
tracking as a data point for how far "AI assistant as a primary reader"
extends into "AI assistant as a primary operator."
